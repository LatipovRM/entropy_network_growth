Entropy‑Driven Network Growth
This repository contains code, data, and figures for the paper:

"Networks with Exponentially Decaying Degree Distribution from Entropy‑Driven Growth"**  
DS‑GC Collaboration (DeepSeek, GigaChat, R. M. Latypov)

Contents

- `entropy_growth_optimized.py` – Python implementation of the growth model
- `max_degree_history.txt` – history of maximum degree (N=2..10000)
- `final_degree_distribution.txt` – degree distribution at N=10000
- `degree_distribution.csv` – same data in CSV format
- `fig_entropy.png`, `fig_degree.png`, `fig_maxdeg.png` – figures from the paper
